damda-recipes

Damda 앱의 파싱 레시피를 호스팅합니다.

이 사이트는 사람이 쓰는 서비스가 아니라, 앱이 읽어 가는 정적 JSON 파일 하나를 놓아둔 곳입니다. 담고 있는 것은 URL 템플릿·HTTP 헤더·정규식·JSON 경로 같은 데이터뿐이며, 실행 코드나 개인정보는 포함하지 않습니다.

  • 현재 레시피: v1/recipes.json
  • 수정·배포 방법: 저장소의 README.md

v1/ 경로는 앱의 schemaVersion 에 대응합니다. 구버전 앱이 계속 읽으므로 기존 경로는 삭제하지 않습니다.
