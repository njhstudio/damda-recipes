# 원본: app/lib/data/resolver/http/host_whitelist.dart 의 kAllowedHostSuffixes
#
# 레시피의 sources.*.hosts 는 이 목록을 벗어날 수 없다. 벗어난 호스트를 적어도
# 앱은 요청하지 않으므로(= 조용히 실패), 검증기가 먼저 거절한다.
#
# ⚠️ 이 파일을 고쳐도 앱은 바뀌지 않는다. 화이트리스트 확장은 **앱 업데이트 사안**이며
#    (docs/09 §1.5), 앱을 먼저 릴리스한 뒤에 이 사본을 맞춰야 한다. 순서를 뒤집으면
#    검증은 통과하는데 실기에서는 동작하지 않는 레시피가 나간다.
#
# 항목은 등록 가능 도메인이다. 호스트가 항목과 같거나 그 서브도메인이면 통과한다.
